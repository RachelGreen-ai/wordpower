# video — Word Power Made Easy short videos

Remotion project that renders vertical **9:16** vocabulary short videos (for
Xiaohongshu / Reels / TikTok / Shorts) — one composition per lesson, 92 s each.

It shares the **single source of truth** with the rest of the repo:

- **Lessons** → imported from [`../web/src/corpus`](../web/src/corpus) (the same
  37 lesson JSONs the learning site uses)
- **Schema** → [`../web/src/corpus-types/vocab.ts`](../web/src/corpus-types/vocab.ts)
- **Audio** → served from [`../web/public`](../web/public) via `Config.setPublicDir("../web/public")`
  in [`remotion.config.ts`](remotion.config.ts), so `staticFile("audio/vocab/...")` resolves there

No lesson or audio data is duplicated here — add a lesson once (see
[`../authoring/AUTHORING.md`](../authoring/AUTHORING.md)) and it's available to
both the site and this video project.

## Run

```bash
npm install
npm run dev            # open Remotion Studio to preview all 37 compositions
```

### Render a video

```bash
npm run render:vocab-intro          # → out/vocab/intro-extro-ambi.mp4
# …or any of the 19 preset scripts (see package.json)

# Render any lesson by its composition id (all 37 available):
npx remotion render VocabAstroGeoBio out/astro-geo-bio.mp4
```

Rendered files go to `out/` (git-ignored). Run `npm run dev` and open Studio to
see every composition id.

## Notes

- **Cross-platform.** Rendering uses a headless Chromium (downloaded on first
  run) and works on any OS — unlike audio *authoring*, which needs Apple Silicon.
- **Prerequisite:** a lesson's audio must already exist in `../web/public/audio/vocab/<lessonId>/`
  (generated by the `authoring/` tool). Missing slots simply render silent.
- Composition ids are **stable** — the `render:vocab-*` scripts depend on them.
